# AutoCut: Real-Time Subtitles & Video Silence Cutter

Комплексный инструмент для стримеров, подкастеров и создателей видео на базе **faster-whisper** и **CUDA**:
1. **Live Subtitles**: субтитры в реальном времени для **OBS Studio** с задержкой ~150–250 мс.
2. **Live Translation**: синхронный перевод речи на английский прямо во время стрима (например, говорите по-русски — субтитры выводятся на английском).
3. **Global Mute Hotkey (F9)**: мгновенная пауза субтитров по кнопке клавиатуры в любой игре или приложении.
4. **AutoCut Video Cutter**: автоматическое удаление пауз и тишины из готовых видео (MP4/MKV) без потери качества.

---

## ⚡ Быстрый старт (1 клик)

### 1. Запуск живых субтитров
Дважды кликните по файлу **`run_live.bat`** (или выполните в консоли):
```powershell
.\.venv\Scripts\autocut.exe live
```
*Ссылка на оверлей автоматически скопируется в буфер обмена!*

### 2. Запуск живого перевода (RU ➔ EN)
Дважды кликните по файлу **`run_live_translate.bat`**:
```powershell
.\.venv\Scripts\autocut.exe live --translate -l ru
```

## 📺 Настройка в OBS Studio

1. В OBS добавьте источник **«Браузер»** (Browser Source).
2. В поле **URL** вставьте ссылку:
   - **Стандарт (белый текст на черной плашке):**  
     `http://localhost:8765/?theme=standard&size=28`
   - **Черный текст на белой плашке:**  
     `http://localhost:8765/?theme=black&size=28`
   - **Без фона (только текст с контрастной обводкой):**  
     `http://localhost:8765/?theme=outline&size=32`
   - **Сверху экрана:**  
     `http://localhost:8765/?theme=standard&pos=top`
   - **Свои цвета и размер:**  
     `http://localhost:8765/?color=yellow&bg=rgba(0,0,0,0.85)&size=34`
3. Установите ширину `1920` и высоту `1080`.

## ✂ Автомонтаж видео (Вырезка тишины)

Удаляет все моменты молчания и затянутые паузы из записи стрима или урока:

```powershell
.\.venv\Scripts\autocut.exe cut my_stream.mp4 -o my_stream_cut.mp4
```

### Дополнительные параметры монтажа:
- `--pause-threshold 0.5`: резать паузы длиннее 0.5 сек (по умолчанию 0.6 с).
- `--margin 0.15`: сохранять запас звука 150 мс вокруг каждого слова.
- `--output-srt cut_subs.srt`: автоматически сгенерировать точные субтитры для нарезанного видео.

---

## ⌨ Горячие клавиши

- **`F9`**: переключение **Mute / Resume** для субтитров (работает глобально в любой игре или полноэкранном приложении).
- Клавишу можно изменить через флаг: `--hotkey pause` или `--hotkey f10`.

## 🛠 Команды CLI

```powershell
# Список подключенных микрофонов
.\.venv\Scripts\autocut.exe devices

# Живые субтитры
.\.venv\Scripts\autocut.exe live [OPTIONS]

# Автоматическая вырезка пауз из видео
.\.venv\Scripts\autocut.exe cut video.mp4 -o cut.mp4
```
