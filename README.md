# AutoCut Live: Real-Time AI Subtitles for OBS & Podcasts

Высокопроизводительный локальный генератор субтитров в реальном времени на базе нейросети `faster-whisper`. Разработан специально для стримов, скринкастов и записи подкастов через **OBS Studio** с ультра-низкой задержкой (~200–400 мс).

---

## ⚡ Как это работает

```
Микрофон (sounddevice)
      │  [аудиопоток 16 кГц, чанки 50 мс]
      ▼
Детекция речи (RMS + Silero VAD) ──(тишина)──> [Пропуск инференса, 0% нагрузки]
      │  [голос обнаружен]
      ▼
Потоковый инференс (faster-whisper)
      │  [жадное декодирование каждые 250 мс, задержка 20-50 мс]
      ├──────────────────────────────┐
      ▼                              ▼
WebSocket + HTTP (:8765)      Файл captions.srt
      │                              │
      ▼                              ▼
OBS Studio (Browser Source)     Готовые таймкоды
(HTML5 / Glassmorphism / CSS)   для YouTube и монтажа
```

1. **Захват аудио**: Библиотека `sounddevice` считывает чистый моно-поток с вашего микрофона в оперативной памяти без задержек ОС.
2. **Умный VAD (фильтр тишины)**: Быстрый замер энергии RMS и Silero VAD отсекают паузы и шум. Нейросеть не нагружается во время молчания и не придумывает ложные фразы (галлюцинации).
3. **Распознавание речи**: Каждые 250 мс скользящий буфер декодируется моделью Whisper для английского языка (`small.en` или `tiny.en`). Инференс длится считанные миллисекунды.
4. **WebSocket трансляция**: Распознанные слова мгновенно отправляются в OBS по локальному вебсокету. Новые слова подсвечиваются мягким неоновым свечением (караоке-эффект).
5. **Экспорт**: По завершении фразы текст с точными таймкодами автоматически пишется в `captions.srt`.

## 📦 Установка

Если виртуальное окружение `.venv` отсутствует, создайте его и установите проект:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

## 🚀 Быстрый запуск

### 1. Просмотр доступных микрофонов

Убедитесь, что система видит ваш микрофон:

```powershell
.\.venv\Scripts\autocut.exe devices
```

Вы увидите таблицу с номерами (Index) и именами устройств. Устройство по умолчанию помечено `★ YES`.

### 2. Запуск сервиса субтитров

Запустите движок одной командой:

```powershell
.\.venv\Scripts\autocut.exe live
```

По умолчанию используются:
- Язык: английский (`en`)
- Модель: `tiny.en` (мгновенный старт и минимальная задержка)
- Тема оформления: `glass` (темный размытый акрил)
- Вывод в файл: `captions.srt`

#### Дополнительные параметры запуска:

```powershell
# Запуск с компактной быстрой моделью tiny.en (для максимальной скорости)
.\.venv\Scripts\autocut.exe live --model tiny.en

# Выбор конкретного микрофона по индексу (например, индекс 1)
.\.venv\Scripts\autocut.exe live --device-index 1

# Выбор темы оформления (glass, neon, cinema, minimal)
.\.venv\Scripts\autocut.exe live --theme neon --size 32
```

## 🎬 Настройка и тестирование в OBS Studio

### Шаг 1: Тест в обычном браузере (перед OBS)

1. Запустите `.\.venv\Scripts\autocut.exe live`.
2. Откройте Google Chrome, Edge или Firefox и перейдите по адресу:
   ```
   http://localhost:8765/?theme=glass
   ```
3. Произнесите в микрофон фразу на английском (например: *"Hello, this is a test of real time captions"*).
4. Вы увидите, как текст плавно появляется внизу экрана в реальном времени, а последнее слово подсвечивается.

---

### Шаг 2: Добавление источника в OBS Studio

1. Откройте **OBS Studio**.
2. В панели **«Источники» (Sources)** нажмите кнопку **`+`** (Добавить).
3. Выберите **«Браузер» (Browser)** и назовите его, например, `Live Subtitles`.
4. В появившемся окне настроек укажите:
   * **URL**: `http://localhost:8765/?theme=glass`
   * **Ширина (Width)**: `1920` (или ширина вашего холста)
   * **Высота (Height)**: `1080` (или высота вашего холста)
   * **Пользовательский CSS**: оставьте пустым (фон виджета уже 100% прозрачен).
   * Поставьте галочку **«Обновлять браузер, когда сцена становится активной»**.
5. Нажмите **ОК**.
6. Разместите источник субтитров на самом верхнем слое сцены поверх захвата экрана или веб-камеры.

## 🎨 Темы и кастомизация оформления

Стиль субтитров настраивается прямо в URL параметрах браузерного источника в OBS:

| Параметр | Возможные значения | Описание |
| :--- | :--- | :--- |
| `theme` | `glass` | Элегантное темное стекло (Glassmorphism), мягкая синяя подсветка слова. |
| `theme` | `neon` | Киберпанк-стиль с фиолетовым свечением и бирюзовым хайлайтом. |
| `theme` | `cinema` | Классический киношный стиль: контрастная темная плашка и желтый текст. |
| `theme` | `minimal` | Без плашек: только чистый четкий текст с глубокой черной обводкой и тенью. |
| `size` | `24`, `28`, `32`, `36`, `44` | Размер шрифта в пикселях (по умолчанию `28`). |
| `hideStatus` | `1` | Скрыть плашку статуса подключения в правом верхнем углу. |

**Пример красивого неонового оверлея для стрима:**
```
http://localhost:8765/?theme=neon&size=32&hideStatus=1
```

## 🛡️ Архитектурная устойчивость (Resilience Architecture)

Система спроектирована для многочасовых бесперебойных стримов и записей:

1. **Кольцевой буфер звука (Zero-Allocation Circular Ring Buffer)**:
   * Фиксированный объем памяти на 15 секунд аудио. Захват звука не выделяет новые массивы в памяти во время стрима (0% задержек сборщика мусора GC) и гарантирует отсутствие дрейфа задержки (lag drift) при длительной работе.
2. **Audio Stream Watchdog (Авто-восстановление микрофона)**:
   * Сторожевой таймер непрерывно следит за поступлением аудиосэмплов. При отключении USB-микрофона, переключении Bluetooth или сбое драйверов Windows звуковой поток автоматически переподключается без падения сервиса.
3. **Inference Gate & Zero-Queue Concurrency**:
   * Атомарный замок гарантирует, что на GPU/CPU выполняется строго одна задача распознавания. Очередь задач не накапливается даже при непрерывной быстрой речи спикера.
4. **Dynamic Adaptive Throttling (Контроль нагрузки на GPU)**:
   * Движок замеряет время каждого инференса. При высокой загрузке системы (тяжелая 3D-сцена или рендер в OBS) интервал шага адаптивно масштабируется, предотвращая просадку FPS на стриме.
5. **Anti-Hallucination & Repetition Guard**:
   * Фильтр отсекает фантомные галлюцинации Whisper (*«Thank you for watching»*, *«Subtitles by...»*) и патологические зацикливания слов на слабом аудиосигнале.
6. **Slow-Consumer Protection (Защита WebSocket)**:
   * Рассылка клиентам защищена таймаутами (150 мс). Зависшее или закрытое окно OBS Browser Source мгновенно изолируется и отключается, не подвешивая весь процесс.
7. **2-Line Auto-Scroll Limiter**:
   * Виджет в OBS автоматически держит текст в пределах 1–2 строк (максимум 14 слов), плавно смещая старые слова и предотвращая переполнение экрана.
